        How to run these prompts (30-second operating guide)
        
    
          
  • Paste as one message. The whole template — role block through schema — goes into a single turn. Splitting it dilutes the constraint stack.
    • 
          
  • Fill the paste block. Each template ends with a marked input block. Put your code, data, contract or transcripts there and delete the placeholder prose.
    • 
          
  • Match effort to stakes. Reasoning effort is a budget, not a quality dial: low for triage, max for proofs and multi-file forensics.
    • 
          
  • Turn on Self-critique for anything a human will sign off on — it forces a verification pass against the quality gates before the answer ships.
    • 
          
  • Reuse as a system prompt. If the model's UI lets you set custom instructions, paste Pillars 1–2 there and keep Pillar 4 as the per-turn request.
    • 
          
  • Engines differ. Switch the model selector and re-copy — the delimiter style, reasoning directive and quirk list are re-tuned automatically.
